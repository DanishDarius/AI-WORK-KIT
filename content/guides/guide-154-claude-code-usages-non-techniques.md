# Claude Code n'est pas réservé aux développeurs

*Claude · 5 min de lecture*

En retirant l'idée de « code » du nom : l'utilisateur décrit, l'outil construit. Installation en cinq minutes et trois projets de week-end à reproduire.

## Le constat

« Claude Code, c'est pour les développeurs » : une idée fausse. C'est pour quiconque possède un dossier de fichiers et une idée claire. Voici ce qui devient possible sans coder.

## Les vrais usages non techniques

**1. Réorganiser un espace Notion ou un espace de stockage.** L'outil pointé sur le dossier peut réorganiser, renommer et étiqueter le contenu.

**2. Croiser des fichiers de données.** Plusieurs exports combinés répondent à une vraie question, plus efficacement qu'un tableur classique.

**3. Auditer un site.** Référencement, accessibilité, fautes de français : un rapport clair en ressort.

**4. Industrialiser ses modèles de documents.** Cinquante propositions clients générées d'un coup, propres et différenciées.

## Le prompt à copier

> **Prompt — audit de dossier**
>
> Tu as accès à ce dossier : [chemin]
>
> Fais-moi un audit en 3 parties :
> 1. Inventaire : qu'y a-t-il dedans, en une page
> 2. Doublons et fichiers à archiver, avec la liste
> 3. Réorganisation proposée : nouvelle arborescence et script de renommage
>
> Pas de code que je ne comprends pas. Explique-moi chaque action en une ligne.

## Sécurité

Toujours travailler sur une copie du dossier, jamais sur l'original.

## À retenir

**L'outil intimide, pas le résultat.**

Une journée d'apprentissage permet d'éviter des semaines de travail manuel — un investissement qui se rentabilise vite.
