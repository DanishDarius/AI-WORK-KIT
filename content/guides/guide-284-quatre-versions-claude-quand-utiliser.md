# Quatre versions de Claude, quatre usages différents

*Claude · 5 min de lecture*

La plupart des utilisateurs parlent de « Claude » comme d'un seul outil, alors qu'il en existe en réalité plusieurs versions. Se tromper de version fait perdre du temps, de l'argent, ou de la qualité selon les cas.

## Les quatre versions

1. **Claude Haiku : la rapide.** Adaptée aux tâches répétitives, au tri d'emails, à l'extraction simple d'information. Peu coûteuse, moins sophistiquée, mais très réactive.
2. **Claude Sonnet : la polyvalente.** Couvre environ 80 % des usages quotidiens : rédaction, analyse, code courant. C'est généralement le choix par défaut le plus adapté.
3. **Claude Opus : la version approfondie.** Réservée à la stratégie, à l'analyse longue, au code complexe, aux décisions importantes. Plus lente et plus coûteuse, à réserver aux cas où la qualité prime sur la vitesse.
4. **Claude Code : l'agent en ligne de commande.** Pas un modèle à proprement parler, mais une interface : un dépôt de code lui est confié, et il exécute fichiers, tests et commits.

## Quand choisir laquelle

Un email rapide ou un résumé court relève de Haiku. Un vrai dossier ou une rédaction complète relève de Sonnet. Une note stratégique ou une refonte importante relève d'Opus. Un travail directement sur du code relève de Claude Code.

## Le prompt d'audit des usages

> **Prompt : audit de tes usages**
>
> Je te liste mes 10 dernières utilisations de Claude :
> [1. type de tâche + résultat attendu]
> ...
>
> Pour chacune :
> 1. Dis-moi quel Claude était optimal (Haiku, Sonnet, Opus, Claude Code)
> 2. Justifie en 1 ligne
> 3. Donne le pourcentage de mes usages mal placés
> 4. Donne-moi la règle simple à retenir

## Le réflexe coûteux à éviter

Utiliser systématiquement Opus « pour être sûr » revient généralement à payer plusieurs fois le prix pour un gain de qualité marginal, sur des tâches où cette différence ne compte pas vraiment.

## À retenir

**La règle simple à retenir.**

Sonnet par défaut, Haiku pour les tâches répétitives, Opus pour les décisions importantes, Claude Code pour le travail sur un dépôt. Le reste relève surtout d'une habitude à corriger.
