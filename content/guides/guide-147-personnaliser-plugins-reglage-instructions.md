# Le réglage qui rend les plugins vraiment utiles

*Claude · 5 min de lecture*

Les plugins deviennent bien plus efficaces après un seul réglage. Lequel, et pourquoi presque personne ne le fait.

## Le constat

Les plugins sont puissants dès l'installation, mais restent génériques par défaut. Un seul réglage change tout : personnaliser leur prompt système. Presque personne ne s'y attarde.

## Le réglage qui change tout

Dans les paramètres du plugin se trouve un champ « instructions personnalisées », parfois masqué sous un menu avancé. C'est là que s'injectent le contexte métier, le ton et les contraintes propres à chaque utilisateur. Sans ce réglage, le plugin s'exprime comme n'importe quel autre.

## Le modèle à coller

> **Prompt - plugin personnalisé**
>
> Tu es [rôle du plugin], mais adapté à mon contexte.
>
> Contexte permanent :
> - Métier : [le mien]
> - Audience : [à qui je m'adresse]
> - Ton : [direct / chaleureux / technique]
> - Ce que je veux toujours en sortie : [format précis]
> - Ce que je refuse : [adjectifs vides, listes à puces génériques, etc.]
>
> À chaque utilisation, applique ces règles avant tout le reste.

## Le test

Lancer la même requête avant et après ce réglage. Si aucune différence ne se voit en trente secondes, le brief reste trop flou.

## À retenir

**Un plugin générique est un plugin gâché.**

Cinq minutes de réglage suffisent pour des mois de gain. Ce réglage mérite d'être fait pour les trois plugins les plus utilisés, et peut être ignoré pour le reste.
