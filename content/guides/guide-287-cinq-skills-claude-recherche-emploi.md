# Cinq Skills Claude pour couvrir tout le cycle de recherche d'emploi

*Claude · 5 min de lecture*

Chercher un emploi sans s'appuyer sur l'IA revient, selon la source, à partir mal équipé pour une épreuve exigeante. Cinq Skills Claude permettent de couvrir l'ensemble du parcours : audit de correspondance au poste, CV, entretien, négociation et suivi après l'entretien.

## Les cinq Skills

1. **Audit de correspondance au poste** : l'offre est analysée pour identifier les points de correspondance clairs et les points nécessitant une argumentation.
2. **Refonte du CV selon l'offre** : un CV ciblé, plutôt que générique, en dix minutes.
3. **Préparation d'entretien** : les quinze questions les plus probables, avec une critique des réponses envisagées.
4. **Négociation salariale** : une fourchette argumentée accompagnée de scripts de réponse.
5. **Emails de suivi** : un contenu ajusté, ni trop insistant ni trop discret.

## Le prompt d'audit de correspondance

> **Prompt : Skill audit de fit**
>
> Voici une offre d'emploi. Voici mon CV. Voici mon contexte (envie, contraintes, attentes salariales).
>
> Analyse :
> 1. Les 5 critères de l'offre où je match clairement (preuves à l'appui).
> 2. Les 3 critères où je vais devoir argumenter.
> 3. Les 2 red flags pour MOI dans cette offre.
> 4. La question piège que le recruteur va probablement poser sur mon parcours.
> 5. Verdict : je postule, je négocie l'offre, je passe.
>
> Sois direct.
>
> [Colle l'offre, le CV, ton contexte]

## Le prompt de négociation salariale

> **Prompt : Skill négo salariale**
>
> Voici l'offre proposée : [montant + package].
>
> Voici mes infos : [poste actuel, expérience, dernier salaire, marché médian connu].
>
> Construis :
> 1. Une fourchette justifiée (basse, cible, plafond) avec 3 arguments par chiffre.
> 2. Le script précis pour ouvrir la négo (1er message ou 1er appel).
> 3. Les 3 contre-arguments à préparer.
> 4. La ligne rouge : à quel chiffre je décline.
>
> Ton : ferme, professionnel, jamais agressif.

## Le garde-fou

Une IA ne connaît pas les détails internes de l'entreprise ciblée. Il reste utile de croiser ses réponses avec l'avis d'une personne interne à cette entreprise (via LinkedIn, un réseau d'anciens élèves, une connaissance commune) avant l'entretien.

## Questions fréquentes

**Pour quels types de postes cela fonctionne-t-il ?**

Pour l'ensemble des postes cadres. Pour des postes techniques très spécialisés, une étape supplémentaire de tests techniques reste recommandée.

**Et pour les jeunes diplômés ?**

Cette approche s'avère encore plus utile dans ce cas : le manque d'expérience se compense en partie par la qualité de la préparation.

## À retenir

**L'emploi se gagne davantage à la préparation qu'au seul talent.**

Les candidats qui obtiennent les meilleurs résultats sont souvent ceux qui arrivent en entretien avec plusieurs heures de préparation solide, plus que ceux avec davantage d'années d'expérience. Ces Skills permettent de condenser cette préparation en une fraction du temps habituel.
