# Cinq artifacts incontournables à construire en un week-end

*Claude · 5 min de lecture*

Les artifacts Claude sont du code interactif généré simplement en conversation. Un CRM personnel, un suivi d'habitudes, une matrice de décision, un planificateur de voyage, un générateur de recettes à partir du contenu du frigo : chacun se construit en moins d'une heure.

## Les cinq incontournables

1. Un CRM personnel : nom, contact, dernière interaction, prochaine action.
2. Un suivi d'habitudes : cinq habitudes suivies, coche quotidienne, graphique hebdomadaire.
3. Une matrice de décision : pondération et scores pour les choix importants.
4. Un planificateur de voyage : budget, jours, réservations réunis dans un seul tableau.
5. Un générateur de repas : à partir du contenu du frigo, propose des recettes adaptées.

## Le prompt pour construire chaque artifact

> **Prompt : artifact builder**
>
> Construis un Artifact HTML autonome pour : [décris le besoin en 2 lignes].
>
> Contraintes :
> - Un seul fichier HTML (CSS + JS inline)
> - Design sobre, utilisable immédiatement
> - Données stockées dans localStorage
> - Responsive
> - Pas de dépendance externe
>
> Sors le code complet.

## Une astuce d'organisation

Conserver ces artifacts dans un dossier « Mes outils » sur le bureau. Ouvrir celui dont on a besoin, fermer les autres. C'est une suite d'outils entièrement personnelle.

## À retenir

**Un artifact utile est celui qu'on rouvre.**

Un outil non réutilisé deux fois dans la semaine qui suit sa création est probablement mal calibré. Mieux vaut le supprimer ou le réécrire que de le laisser inutilisé.
