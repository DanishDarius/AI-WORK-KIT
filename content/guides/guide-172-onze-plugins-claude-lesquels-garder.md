# Les onze plugins Claude : lesquels activer selon son poste

*Claude · 5 min de lecture*

Les plugins (apps et connecteurs) forment une couche que la plupart des utilisateurs ignorent. C'est pourtant précisément là que se cache une bonne partie de la productivité.

## Plugin n'est pas synonyme de connecteur

Un connecteur relie l'assistant à un outil externe (Gmail, Notion). Un plugin ou une app ajoute une capacité (analyser un PDF, générer un artifact spécifique, lancer un workflow métier).

## Cinq plugins à garder activés en permanence

1. La recherche web : pour les recherches récentes
2. L'analyse de fichiers : PDF, Excel, images
3. Les artifacts : pour générer des livrables visuels
4. L'interpréteur de code : pour traiter de la donnée
5. Cowork : pour les tâches longues

## Quand désactiver un plugin

Sur une tâche sensible (confidentialité, sujet légal), désactiver la recherche web et tout ce qui pourrait entraîner une fuite d'information. Cela réduit aussi la consommation de tokens.

## Le prompt d'audit des plugins

> **Prompt : audit plugins**
>
> Liste les plugins/apps actifs sur mon compte.
> Pour chacun :
> 1. À quoi il sert vraiment (en 1 phrase)
> 2. Combien de fois je l'ai utilisé ce mois (estime)
> 3. Devrais-je le désactiver ? (oui/non + raison)

## À retenir

**Moins de plugins, plus de précision.**

Une quinzaine de plugins activés en même temps fait hésiter l'assistant dans ses choix. Cinq plugins bien choisis, à l'inverse, le rendent tranchant. La sobriété gagne aussi sur ce terrain.
