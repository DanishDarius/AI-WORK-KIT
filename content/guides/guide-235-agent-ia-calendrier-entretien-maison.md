# Construire un calendrier d'entretien du logement avec un agent IA

*Multi-outils · 5 min de lecture*

Une chaudière qui lâche en plein hiver, une VMC oubliée depuis des années, un détecteur de fumée à la batterie vide depuis des mois : l'entretien du logement n'est pas compliqué en soi, il est surtout invisible. Un agent IA correctement configuré peut devenir un rappel d'entretien personnalisé - une vingtaine de minutes de configuration pour des économies potentiellement importantes sur l'année.

## Pourquoi un agent plutôt qu'une application dédiée

Les applications d'entretien maison restent génériques : les mêmes rappels s'appliquent à tout le monde. Un logement a pourtant un âge, un système de chauffage, une exposition et des particularités propres. Un agent permet d'adapter le calendrier à ce contexte précis.

## Les sept entretiens les plus souvent oubliés

- Filtre de VMC (une fois par an)
- Détartrage du chauffe-eau (une fois par an)
- Ramonage (une fois par an, obligatoire)
- Batteries des détecteurs de fumée (une fois par an)
- Joints de baignoire et de douche (à inspecter tous les six mois)
- Aération du réfrigérateur, poussière du condenseur (deux fois par an)
- Vérification des gouttières (deux fois par an, automne et printemps)

## Le prompt de calendrier d'entretien sur mesure

> **Prompt - maintenance maison**
>
> Tu es responsable maintenance pour mon logement. Crée un calendrier annuel personnalisé.
>
> MON LOGEMENT :
> - Type : [appart / maison]
> - Âge : [...]
> - Chauffage : [gaz / élec / pompe à chaleur / ...]
> - Eau chaude : [...]
> - VMC : [simple / double flux / aucune]
> - Particularités : [cheminée, jardin, piscine, etc.]
>
> RENDS :
> 1. Calendrier mois par mois, max 2 tâches par mois
> 2. Pour chaque tâche : durée estimée, faisable seule ou pro, coût moyen si pro
> 3. Les 3 entretiens "ne saute jamais" (sécurité / gros coût si oublié)
> 4. Le check trimestriel rapide (10 min, à mettre dans mon calendrier)
> 5. Le "kit minimum" à avoir à la maison (5 outils + 3 consommables)

## À retenir

**Mettre le calendrier d'entretien dans son agenda, pas dans sa mémoire.**

La meilleure liste de tâches d'entretien est celle que le calendrier rappelle automatiquement. Bloquer les créneaux à l'avance, un dimanche soir, pour toute l'année, permet d'éviter la plupart des urgences.
