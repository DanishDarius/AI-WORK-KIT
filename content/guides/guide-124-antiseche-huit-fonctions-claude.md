# Le panorama des huit fonctions principales à connaître

*Claude · 5 min de lecture*

Chat, espaces de travail, agent en arrière-plan, connecteurs, Skills, artefacts, instructions globales, tâches planifiées. Une carte complète pour cesser de laisser du potentiel inexploité.

## Le constat

L'assistant compte huit fonctions principales. La plupart des utilisateurs n'en exploitent qu'une seule : le chat. Voici la carte complète pour ne plus laisser de pouvoir sur la table.

## Chat - le niveau de base

Une question, une réponse. La limite : le contexte se perd à chaque nouvelle conversation. La parade : les espaces de travail.

## Espaces de travail - le contexte qui reste

Un espace de travail réunit des instructions personnalisées et des fichiers. L'assistant se souvient de tout dans chaque conversation de cet espace. Indispensable pour les workflows récurrents.

## Agent en arrière-plan - le travail pendant l'absence

L'assistant lit les fichiers, les e-mails, l'agenda, et travaille pendant que l'utilisateur fait autre chose. Un brief posé le matin, un résultat récupéré le soir.

## Connecteurs - les portes vers les outils

Messagerie, agenda, stockage de fichiers, messagerie d'équipe, gestion de projet, dépôts de code. Sans eux, l'assistant reste un cerveau sans mains ; avec eux, il agit directement dans les outils du quotidien.

## Skills - les compétences sur mesure

Un workflow décrit se transforme en Skill réutilisable : un fichier de définition plus un déclencheur. Ces Skills peuvent être partagés, cédés ou empilés les uns sur les autres.

## Artefacts - les livrables visuels

Tableaux de bord, pages web, documents, présentations, code : l'assistant génère un artefact interactif modifiable en direct, sans quitter la conversation.

## Instructions globales - le style par défaut

Dans les réglages, on précise sa voix, ses formats, ses règles. Elles s'appliquent à toutes les conversations, sauf celles rattachées à un espace de travail qui définit ses propres consignes.

## Tâches planifiées - l'automatisation simple

Il suffit de demander « fais ceci tous les lundis à 8h » pour que le workflow se lance seul. Idéal pour les audits hebdomadaires, les relances, les rapports.

## Le prompt à copier

> **Prompt - récap rapide**
>
> Résume-moi les 8 fonctions principales en une phrase chacune, avec un cas d'usage concret. Format : tableau Markdown.

## À retenir

**Maîtriser une fonction, puis la suivante.**

Ne pas chercher à tout activer d'un coup. Chat, puis espace de travail, puis un connecteur, puis un Skill. Une fois que le premier tourne vraiment, passer au suivant.
