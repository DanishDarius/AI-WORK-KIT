# Quinze mots essentiels pour suivre une conversation sur l'IA

*Multi-outils · 5 min de lecture*

Inutile de connaître deux cents termes techniques. Quinze suffisent pour suivre la grande majorité des conversations sur l'IA sans se sentir largué.

## Les quinze mots essentiels

**LLM** : un modèle qui prédit le mot suivant. Claude, GPT, Gemini en font partie.

**Token** : l'unité de découpe du texte (environ quatre caractères).

**Fenêtre de contexte** : la mémoire courte du modèle au sein d'une session.

**Prompt** : ce qui est écrit au modèle.

**System prompt** : les instructions cachées qui définissent son comportement de base.

**Hallucination** : le moment où le modèle invente une information avec assurance.

**RAG** : quand le modèle va chercher dans une base de données avant de répondre.

**Fine-tuning** : entraîner un modèle sur des données spécifiques.

**Agent** : un LLM capable d'agir, pas seulement de répondre par du texte.

**MCP** : un protocole standard pour connecter un agent à des outils externes.

**Embedding** : la version numérique d'un texte, utile pour la recherche sémantique.

**Inférence** : l'acte de générer une réponse, l'étape qui a un coût de calcul.

**Modèle de raisonnement** : un modèle qui « réfléchit » avant de répondre (o1, le mode réflexion de Claude).

**Multimodal** : capable d'accepter texte, image et audio.

**Skill** : un workflow réutilisable, packagé pour un agent.

## Le prompt d'auto-évaluation

> **Prompt : quiz toi-même**
>
> Pose-moi 10 questions sur les termes : LLM, token, context window, RAG, agent, MCP, embedding, inference, hallucination, fine-tuning.
> Format : QCM 4 options.
> Corrige en fin avec explication pour chaque erreur.

## À retenir

**Le vocabulaire, c'est déjà une forme d'appartenance.**

Connaître ces quinze mots ne rend pas expert. Mais cela évite de faire semblant en réunion, et c'est déjà considérable.
